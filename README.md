# Serie A Blog Core

Proyecto Java desarrollado para practicar modelado de dominio,
repositorios y gestión de información relacionada con la Serie A.

## Tecnologías

- Java 21
- Maven
- Spring Boot

## Estructura

- Jugador
- Equipo
- Articulo
- CronicaPartido

## Objetivos

- Aplicar POO
- Implementar patrón Repository
- Preparar la base para futuras APIs REST

## Cómo ejecutar

```bash
mvn spring-boot:run
